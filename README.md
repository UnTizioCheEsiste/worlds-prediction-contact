# Worlds Prediction Engine — Provider Contact

Worlds Prediction Engine is a non-commercial project for League of Legends World Championship analytics and statistical predictions.

This repository is a public contact point for data providers and API administrators. It contains contact and support information only. **It is not the project's main source-code repository.**

## Contact the maintainer

Please [open a GitHub Issue](https://github.com/UnTizioCheEsiste/worlds-prediction-contact/issues/new/choose) using the **API / Data Provider Contact** template. You can raise questions about API access, attribution, integration behavior, data reuse, or a request to change or stop an integration. The maintainer can respond in the same issue.

No personal email address or other personal information is required. Issues are public: do not include credentials, access tokens, private data, or sensitive information.

The existence of this contact channel does not imply that an API provider has approved an integration or accepted this contact method. Provider-specific authorization and terms must be confirmed separately.
